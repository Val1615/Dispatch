# Dispatch IDF V9.0

Mise à jour majeure consacrée aux clients durables et aux lignes régulières.

## Nouvelle catégorie : Lignes régulières

La catégorie est séparée du marché du fret et contient cinq onglets :

- appels d'offres ;
- lignes obtenues ;
- rotations à planifier ;
- portefeuille clients ;
- calendrier contractuel sur sept jours.

Les consultations locales se débloquent à partir de 60 de réputation ou après douze livraisons. Les dossiers les plus importants apparaissent surtout aux niveaux de réputation élevés.

## Appels d'offres

Le joueur construit une offre commerciale avec :

- un prix par rotation ;
- un niveau de service ;
- la garantie éventuelle d'un ensemble de remplacement.

Le résultat dépend du prix, de la réputation, de la relation avec le client et des garanties proposées. Le client peut accepter, refuser ou transmettre une contre-proposition.

## Types de lignes

- navette simple ;
- navette aller-retour ;
- ligne intersites ;
- distribution multi-points avec trois à quatre livraisons rapprochées ;
- tournée de ramasse ;
- ligne mixte avec distribution et collecte de retour.

Une ligne remportée génère automatiquement ses rotations selon le calendrier. Chaque rotation peut être envoyée vers la planification avec toutes ses étapes déjà regroupées.

## Relations commerciales

Les livraisons ponctuelles et régulières font évoluer la relation avec chaque client. La ponctualité, les dommages, les rotations manquées, les appels d'offres et les résiliations influencent cette relation.

Les lignes actives peuvent être renégociées sur :

- le prix ;
- le nombre de rotations hebdomadaires ;
- l'ajout d'une destination ;
- le retrait du dernier point de la ligne.

Il est également possible de suspendre ou de résilier un contrat, avec les conséquences commerciales correspondantes.

## Portefeuille de clients

La base comprend 69 entreprises fictives et parodiques inspirées de grandes enseignes reconnaissables, réparties entre :

- grande distribution ;
- alimentaire et froid ;
- e-commerce et messagerie ;
- bricolage et matériaux ;
- commerce et équipement ;
- industrie et automobile ;
- pharmacie et cosmétique ;
- environnement et recyclage.

Leur profil influence les marchandises proposées, les tarifs, l'exigence horaire et le temps moyen passé au quai.

## Compatibilité

Les sauvegardes V8.9.5 sont migrées automatiquement. Les anciens contrats et clients locaux restent utilisables.
