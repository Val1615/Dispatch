# Dispatch IDF V9.3

Version GitHub Pages du jeu de gestion de transport.

## Installation

Déposez ensemble à la racine du dépôt GitHub Pages :

- `index.html`
- `.nojekyll`
- le dossier `assets_annex/`

## Patch V9.3

- correction automatique des plaques manquantes sur les tracteurs achetés ;
- plaques françaises uniques et modifiables ;
- numéros de parc automatiques `TR-001` et `SR-001`, également modifiables ;
- catalogue de remorques neuves considérablement enrichi ;
- marché de l’occasion multigénération pour les remorques ;
- filtres, tris, financement, options, inspection, négociation et revente ;
- fiabilité séparée du châssis, des essieux, des freins, de l’électricité, de la caisse et du groupe froid ;
- dossier individuel et suivi économique des remorques ;
- migration automatique des sauvegardes précédentes.
